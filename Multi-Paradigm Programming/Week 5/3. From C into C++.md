# Core differences
- **Paradigm:** C++ is **object-oriented** (uses Classes, Objects). C is **procedural** (uses structs, functions).
- **Booleans:** `bool`(`true`, `false`) is a built-in type in C++. In C, you must `#include <stdbool.h>`.

---
# Key feature comparisons
- **Strings**
	- **C:** uses null-terminated `char` arrays (e.g., `char name[30]`). Requires functions like `strlen()` for length and `strcmp()` for comparison.
	- **C++:** provides a `string` class. You can use operators like `==` for comparison and `+` for concatenation. Length is a method: `name.length()`.
- **Input/Output (I/O)**
	- **C:** uses `printf` and `scanf` from `<stdio.h>`.
	- **C++:** uses stream objects `cout` (output) and `cin` (input) with `<<` and `>>` operators from `<iostream>`.
- **Memory allocation**
	- **C:** uses `malloc()` and `free()` from `<stdlib.h>`.
		- `int *array = (int*)malloc(sizeof(int) * 10);`
		- `free(array);`
	- **C++:** uses `new` and `delete` operators.
		- `int *array = new int[10];`
		- `delete [] array;` (note the `[]` for arrays)
- **Pointers and references**
	- C++ supports C-style pointers.
	- C++ adds **references** (declared with `&`). A reference is an *alias* for an existing variable; it cannot be null and must be initialised.
	- **Code:**
```c++
int x = 10;
int& xRef = x; //xRef is now an alias for x.
xRef = 23; //This changes x to 23.
```

# Function arguments
- **Call by Value (C & C++)**
	- A **copy** of the variable is passed. The original is not modified.
	- `void aFunction(int aNumber) { ... }`
	- `aFunction(x);`
- **Call by Reference (C-style pointers)**
	- The **memory address** (pointer) is passed. The function can modify the original value using `*` (dereference).
	- `void aFunction(int *aNumber) { *aNumber = 22; }`
	- `aFunction(&x);`
- **Call by Reference (C++ style references)**
	- A **reference** (alias) to the variable is passed. This is syntactically cleaner and safer (no null pointers).
	- `void aFunction(int &aNumber) { aNumber = 22; }`
	- `aFunction(x);`

# Object-oriented C++
- **Structs (C) vs. Classes (C++)**
	- In C, `structs` hold data, and functions that operate on them are separate.
	- In C++, **Classes** bundle data (fields) and behavior (methods) together.
	- **Encapsulation:** C++ classes use `private:` (hides data) and `public:` (exposes methods) to control access.
	- **Example:**
```c++
// C++ Book class
class Book {
private:
	string title; //data is private
public:
	void setTitle(string newTitle) {
		title = newTitle;
	}
};

Book b;
b.setTitle("My title!"); //use the method
```
- **Namespaces**
	- C++ uses namespaces in group code and prevent naming conflicts (e.g., `std`).
	- You can access items with the scope resolution operator `::` (e.g., `std::cout`) or import the namespace with `using namespace std;`.

# Other major C++ features
- **File handling:** C++ uses object-oriented stream classes from `<fstream>`: `ofstream` (output), `ifstream` (input). You use methods like `.open()` and operators `<<`/`>>`.
- **Collections (STL):** the Standard Template Library (STL) provides powerful, generic collection classes.
	- `vector` is a dynamic, resizable array.
	- `myBooks.push_back(book1);` //add item
	- `myBooks.pop_back();` //remove last item
- **Exception handling:** C++ has built-in error handling with `try`/`catch` blocks to manage errors at runtime.
- **Templates:** allows you to write generic functions and classes that work on any data type (`template <typename T`).
```c++
template <typename T>
T Max (T a, T b) {
	return (a > b) ? a : b;
}
```
