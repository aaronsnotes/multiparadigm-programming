# What is Time Complexity?
- A way to measure the time an algorithm takes to complete.
- It's a **relative measure** of the **number of operations**, not a specific time in seconds.
- Expressed using **Big 'O' Notation** (e.g., $O(n)$) to describe performance as the input size 'n' grows.
- Let us compare algorithm scalability.

---
# Common Big 'O' Notations
- **$O(1)$ - Constant time**
	- Takes the same number of operations regardless of input size 'n'.
	- **Example:** accessing a specific array element `array[0]` or Stack `push`/`pop`.
- **$O(n)$ - Linear Time**
	- Operations grow linearly with 'n'.
	- **Example:** finding the minimum value in an **unsorted** array (must check all 'n' elements).
- **$O(logn)$ - Logarithmic Time**
	- "Divide and conquer" approach; the problem size is halved (or reduced) at each step. Very efficient.
	- **Example: Binary Search** in a **sorted** array. You check the midpoint, then discard half the data and repeat.
- **$O(n^2)$ - Quadratic Time**
	- Operations grow as the square of 'n'. Scales poorly.
	- **Example:** a **nested loop** that runs `n * n` times.
	- **Example: Bubblesort** (worst case), which requires 'n' passes, each doing 'n' operations.
- **$O(2^n)$ - Exponential Time**
	- Operations double with each new element. Extremely slow and does not scale.
	- **Example:** brute-force password guessing.

---
# Best, worst, and average cases
An algorithm's performance can depend on the input data.
- **Example: Linear Search (find a value in an unsorted array)**
	- **Best case $O(1)$:** value is the first item.
	- **Worst case $O(n)$:** value is the last item, or not in the array.
	- **Average case $O(n)$:** value is somewhere in the middle (e.g., $O(n/2)$), which simplifies to $O(n)$.
- **Example: Binary Search Tree (add node)**
	- **Best case $O(1)$:** tree is empty (add a root).
	- **Average case $O(logn)$:** the tree is "balanced", so you discard half the nodes at each step.
	- **Worst case $O(n):** the tree is "unbalanced" (a straight line, like a linked list), which happens if you insert data in sorted order.
