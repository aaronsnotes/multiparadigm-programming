# C Streams
- **Concept:** C uses "streams" for I/O, representing a flow of information. All file I/O requires `<stdio.h>`.
- **Built-in streams:**
	- `stdin`: standard input (keyboard).
	- `stdout`: standard output (screen).
	- `stderr`: standard error (screen).
- **File streams:** use a `FILE` pointer, e.g., `FILE *fp;`.

---
# Opening and closing files
- `fopen()`: opens a file and links it to a stream.
	- **Syntax:** `FILE *fopen(const char *filename, const char *mode);`.
	- **Returns:** a `FILE` pointer on success, or `NULL` on failure. You **must** check for `NULL`.
- `fclose()`: closes the file, freeing resources.
	- **Syntax:** `int fclose(FILE *filePtr);`.

---
# File access modes
The `mode` string in `fopen()` defines the operation:

| Mode   | Description                               |                                                          |
| ------ | ----------------------------------------- | -------------------------------------------------------- |
| `"r"`  |                                           | **Read** (file must exist).                              |
| `"w"`  |                                           | **Write** (creates new file, or **truncates** existing). |
| `"a"`  |                                           | **Append** (creates new, or adds to end of existing).    |
| `"r+"` | Read and write (must exist).              |                                                          |
| `"w+"` | Read and write (creates or truncates).    |                                                          |
| `"a+"` | Read and append (creates or adds to end). |                                                          |

---
# Writing to files
- `fputc()`: writes a single character.
	- `int fputc(int c, FILE *fp);`
- `fputs()`: writes a null-terminated string.
	- `int fputs(const char *s, FILE *fp);`
- `fprintf()`: writes formatted output, just like `printf` but to a file.
	- `int fprintf(FILE *fp, const char *format, ...);`

---
# Reading from files
- `fgetc()`: reads a single character, returns as `int` or `EOF` (End of File).
	- `int fgetc(FILE *fp);`
- `fgets()`: reads a line of text (up to `n-1` chars, or `\n`).
	- Includes the newline `\n` in the string.
	- Returns pointer to string, or `NULL` at EOF.
	- `char *fgets(char *s, int n, FILE *fp);`
- `fscanf()`: reads formatted input, just like `scanf`.
	- `int fscanf(FILE *fp, const char *format, ...);`

---
# Parsing and converting text
- **Converting strings:** use `<stdlib.h>`.
	- `atoi()`: converts a string to an `int`.
	- `atof()`: converts a string to a `double` (float).
- **Parsing delimited text (CSV):**
	- Manually parsing (looping char by char) is complex.
	- `strtok()` from `<string.h>` is a better way.
	- **Syntax:** `char *strtok(char *str, const char *delimiter);`.
	- **How it works:**
		1. Call `strtok()` with the string and delimiter to get the *first* token.
		2. Call `strtok()` with `NULL` as the first argument to get all *subsequent* tokens from the same string.
