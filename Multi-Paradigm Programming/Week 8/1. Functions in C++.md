# Basic Functions
- Functions in C have the same basic syntax as in C:
```
return_type function_name(parameters) {
	//body of the function
}
```

```cpp
#include<iostream>
using namespace std;
int add(int x, int y) {
	return (x+y);
}
int main() {
	cout << "3+4=" << add(3, 4) << endl;
	return 0;
}
```

# Call-by-reference
When calling a function, there are three ways that arguments can be passed to a function:
1. **Call by Value:** copies the actual value of an argument into the formal parameter of the function; changes made to the parameter inside the function have no effect on the argument.
2. **Call by Pointer:** copies the address of an argument into the formal parameter. Inside the function, the address is used to access the actual argument used in the call. This means that changes made to the parameter affect the argument.
3. **Call by Reference:** copies the reference of an argument into the formal parameter. Inside the function, the reference is used to access the actual argument used in the call. This means that changes made to the parameter affect the argument.

## Call-by-value
```cpp
#include<iostream>

using namespace std;

void increment(int x) {
	x++;
}

int main() {
	int x = 1;
	cout << "x: " << x << endl;
	increment(x);
	cout << "x: " << x << endl;
	return 0;
}
```
#### Output:
```
x: 1
x: 1
```

## Call-by-pointer
Changes the value of x:
```cpp
#include<iostream>

using namespace std;

void increment(int *x) {
	(*x)++;
}

int main() {
	int x = 1;
	cout << "x: " << x << endl;
	increment(&x);
	cout << "x: " << x << endl;
	return 0;
}
```

#### Output:
```
x: 1
x: 2
```

## Call-by-reference
Changes the value of x (simpler and tidier):
```cpp
#include<iostream>

using namespace std;

void increment(int &x) {
	x++;
}

int main() {
	int x = 1;
	cout << "x: " << x << endl;
	increment(x);
	cout << "x: " << x << endl;
	return 0;
}
```

#### Output:
```
x: 1
x: 2
```
