# Basic Functions
- Functions in C have the same basic syntax as in C:
```
return_type function_name(parameters) {
	//body of the function
}
```

```cpp
#include<iostream>
using namespace std;
int add(int x, int y) {
	return (x+y);
}
int main() {
	cout << "3+4=" << add(3, 4) << endl;
	return 0;
}
```
