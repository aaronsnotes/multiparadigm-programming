# Object Oriented Programming
- One of the main motivations behind the creation of C++ was to add object orientation to the C programming language.
- The core of object-oriented programming is to create an object, in code, that has certain properties and methods.
- For example, a car is an object which has certain properties such as colour, number of doors, etc.
- It also has certain methods such as acceleration, brake, etc.

# Classes
- Classes are the central feature of C++ that support object-oriented programming.
- Classes are also sometimes referred to as user-defined types.
- A class is used to specify the form of an object.
- It combines data relating to the object and function for manipulating that data.
- The data and functions within a class are called members of the class.
- When you define a class, you define the **blueprint** for an object.
- This doesn't actually define any data, but it does define what the class name means, that is:
	- What an object of the class will consist of,
	- And what operations can be performed on such an object.

A class definition starts with the keyword 'class' followed by the class name and the class body, enclosed by a pair of curly braces.

**A class definition must be followed by a semicolon.**
```cpp
class Rectangle {
	public:
		double width;
		double height;
};
```
*The keyword 'public' determines the access attributes of the members of the class that follows it.*

# Objects
- An object is a specific item of the type represented by the class.
- We declare objects of a class with exactly the same sort of definition that we declared variables of the basic types.
- The following statements declare two objects of the class Rectangle:
```cpp
Rectangle rect1;
Rectangle rect2;
```
*This is just the same as declaring an integer variable (`int num;`) or any of the other built-in types.*

# Accessing public members
The public members of objects of a class can be accessed using the direct member access operator '.'.
```cpp
class Rectangle {
	public:
		double width;
		double height;
};

int main() {
	Rectangle rect;
	rect.width = 3.0;
	rect.height = 2.0;
	double area = rect.width * rect.height;
	cout << "Area of rect: " << area << endl;
	return 0;
}
```

#### Output:
```
Area of rect: 6.0
```

# Member functions
A member function of a class is a function that has its definition or its declaration within the class definition like any other variable.

It operates on any object of the class of which it is a member, and has access to all the members of a class for that object.
```cpp
class Rectangle {
	public:
		double width;
		double height;
		
		double get_area() {
			return width * height;
		}
}
```

# Access specifiers
- Data hiding is one of the important features of Object Oriented Programming, which allows preventing the functions of a program to access directly the internal representation of a class type.
- The access restriction to the class members is specified by the labelled **public**, **private**, and **protected** sections within the class body.
- The Keywords public, private, and protected are called access specifiers.

# Members
## Public members
- A public member is accessible from anywhere outside the class but within a program.
- You can set and get the value of public variables without using a member function.

## Private members
- A private member variable or function cannot be accessed, or even viewed from outside the class. Only the class and friend functions can access private members.
- By default all the members of a class would be private, for example in the following class width is a private member:
```cpp
class Rectangle {
	double width;
	public:
		double height;
}
```
*Generally, we keep data private and allow access through public functions.*

## Protected members
- A protected member variable or function is very similar to a private member but it provides access from derived classes.

# The class constructor
- A class constructor is a special member function of a class that is executed whenever we create new objects of that class.
- A constructor will have exact same name as the class and it does not have any return type at all, not even void. Constructors can be very useful for setting initial values for certain member variables.
```cpp
Rectangle::Rectangle(double w, double h) {
	cout << "Creating a rectangle" << endl;
}
```

# Parameterized constructors
- A default constructor does not have any parameter, but if you need, a constructor can have parameters.
- This helps you assign initial values to an object at the time of its creation.
```cpp
Rectangle::Rectangle(double w, double h) {
	cout << "Creating a rectangle" << endl;
	width = w;
	height = h;
}
```

# Default parameters
- Function definitions in C++ can specify default values for parameters:
```cpp
int addx(int n, int x=1) {
	return n+x;
}

int main() {
	cout << addx(3,5) << endl;
	cout << addx(3) << endl;
	return 0;
}
```

```
8
4
```
- This can be used when writing constructors to make parameters optional:
```cpp
Rectangle::Rectangle(double w=1.0, double h=1.0) {
	...
}
```

# Friend functions
- A friend function of a class is defined outside that class's scope but it has the right to access all private and protected members of the class.
- Even though the prototype for friend functions appear in the class definition, friends are **not** member functions.

# The 'this' pointer
- Every object in C++ has access to its own pointer through an important pointer called 'this' pointer.
- The 'this' pointer is an implicit parameter to all member functions. Therefore, inside a member function, this may be used to refer to the invoking object.
- Can be useful in constructors:
```cpp
Rectangle::Rectangle(int width) {
	this->width = width;
}
```
- Or to pass the current object as a parameter to other, non-class functions:
```cpp
void do_something(Rectangle *rect);
void Foo::DoSomething() {
	do_something_to_a_foo(this);
}
```

# Static members
- We can define class members static using 'static' keyword.
- When we declare a member of a class as static it means no matter how many objects of the class are created, there is only one copy of the static member.
- A static member is shared by all objects of the class.
- All static data is initialised to zero when the first object is created, if no other initialisation is present.
- If we want to initialise a static member, this must be done outside the class using the scope resolution operator '::' to identify which class it belongs to.
