# Overloading
We have seen previously how we can overload regular functions, that is how we can have more than one definition for a function as long as the arguments for each function differ in:
- number
- data type
- or, both number and data type.

# Operator overloading
Another application of overloading which is particularly useful in object-oriented programming is the ability to change the functionality of operators: **operator overloading**.

For example, we can add together two integers:
```cpp
#include<iostream>
int main() {
	int i = 1; int j = 2;
	int k = i + j;
	std::cout << "k = " << k << std::endl;
	return 0;
}
```

```
k = 3
```
But what does it mean to add together two user-defined types (e.g., two objects of the class Rectangle)?

- Most of the built-in operators available in C++ can be overloaded. Thus, we can use operators with user-defined types as well.
- Overloaded operators are functions with special names: the keyword "operator" followed by the symbol for the operator being defined.
- Like any other function, an overloaded operator has a return type and a parameter list. E.g.:
```cpp
Rectangle operator+(const Rectangle& r1, const Rectangle& r2);
```

## Adding rectangles
- When we overload an operator, it is up to us what we want to happen. E.g.:
```cpp
Rectangle operator+(const Rectangle& r) {
	Rectangle rect;
	rect.width = this->width + r.width;
	rect.height = this->height + r.height;
	return rect;
}
```
- In this case we are simply adding the widths and heights.
- NOTE: the function here is a member function of the Rectangle class, so only requires one additional parameter. If it were defined outside the class, we would need to provide both rectangles that we are adding as parameters.

# Overloading other operators
- Arithmetic operators (`+, -, *, /, %`) can all be overloaded in the same way as we have seen for '+'.
- Relational operators (`<, >, <=, >=, ==,`etc.) are similar, but must return a Boolean value.
```cpp
bool operator<(const Rectangle& r) {
	...
}
```
- The increment (`++`) and decrement (`--`) operators should be overloaded for postfix and prefix usage.
```cpp
Rectangle& operator++() {
	...
}

Rectangle operator++(int) {
	...
}
```

# Overloading I/O operators
- `cout` is an object of `iostream` class which is a compiler defined class (`cin` is an object of the `istream` class).
- When we do `cout << obj` where `obj` is an object of our class, the compiler first looks for an operator function in `ostream`, then it looks for an operator function in `ostream`, then it looks for a global function.
- So, we make a global function and, if we want to allow it to access private data members of our class, we must make it a 'friend'.
```cpp
friend ostream& operator<< (ostream &output, const Rectangle &r) {
	...
}

friend istream& operator>> (istream &input, Rectangle &r) {
	...
}
```
