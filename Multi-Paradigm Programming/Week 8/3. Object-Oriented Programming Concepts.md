# Encapsulation
- **Encapsulation** is a means of hiding details *in order to protect them from outside manipulation*.
- We do this my putting a box around something to protect its contents.
- Wrapping up data and functions together into a single unit (i.e., Class) is a means of Encapsulation.

# Inheritance
- One of the more important concepts in object-oriented programming is that of inheritance.
- Inheritance allows us to define a class in terms of another class.
- When creating a class, we can designate that the new class should inherit the members of an existing class.
- This existing class is called the base class, and the new class is referred to as the derived class.
- The idea of inheritance implements the **is a** relationship.
- We saw an example of this last time -- a Square **is a** rectangle (with equal sides).![[Screenshot 2025-11-10 at 12.18.59.png]]
- To define a derived class, we use a class derivation list to specify the base class(es).
- A class derivation list names one or more base classes and has the form:
	- `class derived-class: access-specifier base-class`
- For example:
```cpp
class Square: public Rectangle {
	...
};
```
- The access specifier can be any of **public**, **private**, or **protected**.
- This can be used to change the access for inherited members when accessed **outside** the derived class.

| **Access Specifier in base class** | **Public inheritance** | **Protected Inheritance** | **Private Inheritance** |
| ---------------------------------- | ---------------------- | ------------------------- | ----------------------- |
| **public**                         | public                 | protected                 | private                 |
| **protected**                      | protected              | protected                 | private                 |
| **private**                        | inaccessible           | inaccessible              | inaccessible            |
- If no access specifier is given, then it is **private** by default.

# Types of inheritance
- Single inheritance
![[{E017DB2F-5B7D-4481-BC3D-EDE9D9437A2E}.png]]
```cpp
class Square: public Rectangle {
	...
};
```

- Hierarchical inheritance
![[Pasted image 20251110123057.png]]
```cpp
class Rectangle: public Shape {
	...
};

class Ellipse: public Shape {
	...
};
```

- Multi-level inheritance
![[Pasted image 20251110123328.png]]
```cpp
class Rectangle: public Shape {
	...
};

class Square: public Rectangle {
	...
};
```

- Multiple inheritance
![[Pasted image 20251110123641.png]]
```cpp
class Rectangle: public Shape, public Printable {
	... //inherits from both base classes
};
```

# Polymorphism
- The word **polymorphism** means having many forms.
- In a programming language that shows polymorphism, objects of classes belonging to the same hierarchical tree (inherited from a common base class) may possess functions bearing the same name, but each having different behaviours.
- E.g., all shapes have an area, but it is calculated differently depending on the shape:
	- Rectangle: $area = width * height$
	- Triangle: $(width * height) / 2$
	- Circle: $pi * (width / 2) * (width / 2)$

# Abstraction
- **Abstraction** is a means of hiding details *in order to simplify an interface*.
- Using a car as a example, all of the controls in a car are abstractions. This allows you to operate a vehicle without understanding the underlying details of the steering, acceleration, or deceleration systems.
- Public member functions provide an abstract interface to the class so the user does not need to know what is being done, just what the effect is.
