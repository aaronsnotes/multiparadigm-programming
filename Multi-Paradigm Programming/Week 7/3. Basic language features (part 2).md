# Arrays
Arrays store multiple items of the same data type. They are **indexed from 0**.
- **Declaration:** `int nums[6];`
- **Initialisation:** `int nums[6] = {1, 2, 3, 4, 5, 6};`
- **2D arrays:** `int twoD[2][3] = { {1, 2, 3}, {4, 5, 6} };`
	- (The value of `twoD[0][1]` is 2.)

## Limitations of C-style arrays
- **Fixed size:** they are not extensible.
- **No direct copy/compare:** cannot be copied or compared using `=` or `==`.
- **Functions:** cannot be returned directly from functions (you must return a pointer).

## Additional example: 2D array
```cpp
#include <iostream>
using namespace std;

int main() {
	int twoD[2][3] = { {1, 2, 3}, {4, 5, 6} };
	
	//loop through each row
	for (int i = 0; i < 2; ++i) {
		//loop through each column in that row
		for (int j = 0; j < 3; ++j) {
			cout << "twoD[" << i << "][" << j << "] = " << twoD[i][j] << endl;
		}
	}
	return 0;
}
```

#### Output:
```
twoD[0][0] = 1
twoD[0][1] = 2
twoD[0][2] = 3
twoD[1][0] = 4
twoD[1][1] = 5
twoD[1][2] = 6
```

# Vectors
Vectors are the C++ standard library's solution to arrays. They are **extensible** (dynamic) arrays.
- **Header:** you must include the vector library: `#include <vector>`.
- **Declaration:** `vector <type> v;`
- **Advantages:** unlike arrays, vectors can be copied, compared (`==`), and returned directly from functions.
- **Efficiency:**
	- Reasonably low memory use.
	- Allow random access (like arrays).
	- **Inefficient** at inserting or removing elements *except* at the end.

## Common vector functions
- `size()`: returns the number of elements.
- `resize()`: changes the size:
- `empty()`: returns `true` if the vector is empty.
- `assign()`: replaces all elements with new values.
- `front()`: access the first element.
- `back()`: access the last element.
- `push_back()`: adds an element to the end.
- `pop_back()`: removes the last element.
- `clear()`: removes all elements.

### Example: using `vector`
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
	vector <int> v;
	v.assign(5, 0); //fills vector with 5 elemenys, all set to 0.
	v.push_back(1); //adds 1 to the end
	
	cout << "The vector elements are: ";
	//use .size() to control the loop
	for (int i = 0; i < v.size(); i++) {
		cout << v[i] << " ";
	}
	cout << endl;
	return 0;
}
```

#### Output:
```
The vector elements are: 0 0 0 0 0 1
```

# Iterators
Iterators are special pointers that can iterate over members of a container (like `vector` or `string`). They are useful for containers that don't have index access (like sets or lists).

## Example: vector iterator
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
	vector <int> v;
	v.assign(5, 0);
	v.push_back(1);
	
	cout << "The vector elements are: ";
	//declare an iterator for a vector of ints
	vector<int>::iterator it;
	
	//loop from beginning to the end
	for (it = v.begin(); it != v.end(); ++it) {
		//use *it to dereference the iterator and get the value
		cout << *it << " ";
	}
	cout << endl;
	return 0;
}
```

#### Output:
```
The vector elements are: 0 0 0 0 0 1
```

# Strings
C++ does not have a native string type. Instead, the standard library provides a powerful `string` class.
- **Header:** `#include <string>`
- **Namespace:** part of `std`, so use `std::string` or `using namespace std;`.
- **Quotes:** strings use **double quotes** (`"a string"`), while characters use **single quotes** (`'a'`).

## Strings vs. character arrays
- `string` variables automatically resize; `char` arrays do not.
- You can assign a `char` array to a `string`.
```cpp
char colour[4] = {'r', 'e', 'd', '\0'};
string text;
text = colour;
```
- `getline()`**for input:** the `getline()` function reads an entire line from an input stream, stopping at the newline character `\n`. `getline(cin, str);`
	- **Warning:** be careful mixing `cin >>` and `getline()`. `cin >>` leaves the newline character in the input buffer, which `getline()` will read as an empty line.

### Additional example (recreating `getline.cpp`):
```cpp
#include <iostream>
#include <string>
#include <limits> //for numeric_limits

using namespace std;

int main() {
	int age;
	string fullName;
	
	cout << "Enter your age: ";
	cin >> age;
	
	//problem: cin >> age leaves the '\n' in the buffer.
	
	//fix: we must ignore the leftover newline character before calling getline()
	cin.ignore(numeric_limits<streamsize>::max(), '\n');
	
	cout << "Enter your full name: ";
	getline(cin, fullName);
	
	cout << "Age: " << age << endl;
	cout << "Name: " << fullName << endl;
}
```
- **Converting strings (string streams):** you cannot convert strings directly to numbers. You must use the **String Stream** library.
	- **Header:** `#include <sstream>`
	- **Process:** load values into the `stringstream` with `<<`, then extract them with `>>`.

### Additional example (re-creating `convert.cpp`):
```cpp
#include <iostream>
#include <string>
#include <sstream> // 

using namespace std;

int main() {
    string s_num = "123";
    int i_num;

    // Convert string to int
    stringstream ss(s_num); // 
    ss >> i_num; // 

    cout << "String value: " << s_num << endl;
    cout << "Integer value: " << i_num << endl;
    
    // Convert int to string
    int another_num = 456;
    string another_s;
    
    stringstream ss2;
    ss2 << another_num;
    ss2 >> another_s;
    
    cout << "Integer value 2: " << another_num << endl;
    cout << "String value 2: " << another_s << endl;
}
```
