# Data types
- **Primitives:** `char`, `int`, `float`, `double` (same as C, with modifiers like `signed`, `unsigned`, `short`, `long`).
- `bool`: a C++ native type with values `true` (1) and `false` (0). Any non-zero value is implicitly converted to `true` (1).

## Example: `bool` in C++
```cpp
#include <iostream>
using namespace std;

int main() {
	bool b = true; //1
	bool c = false; //0
	bool d = 1; //1
	bool e = 0; //0
	bool f = 0.3; //1 (non-zero)
	cout << b << c << d << e << f << endl;
	return 0;
}
```

#### Output:
```
10101
```
(The compiler will warn about the `double` to `bool` conversion.)

# Type casting
You can force a conversion from one data type to another using a C-style cast: `(type) expression`.

## Example: type casting
```cpp
#include <iostream>
using namespace std;

int main() {
	double a = 21.09399;
	int b = 0, c = 100;
	
	//casting double to int truncates the decimal
	b = (int) a;
	cout << "a = " << a << " (int)a = " << b << endl;
	
	//integer division
	cout << "c = " << c << " c/3 = " << c/3 << endl;
	
	//float division
	float d = (float) c;
	cout << "c = " << c << " (float)c/3 = " << d/3 << endl;
}
```

#### Output:
```
a = 21.094   (int)a = 21
c = 100   c/3 = 33
c = 100   (float)c/3 = 33.3333
```

# Constants
There are two ways to define constants:
1. `#define` **(pre-processor):** `#define identifier value`. This is an older C-style method. It's a simple text replacement done before compilation.
2. `const` **(Keyword):** `const type variable = value;`. This is the modern C++ way. It's type-safe and respects scope.

## Example: constants
```cpp
#include <iostream>
using namespace std;

//C-style pre-processor definition (no ';')
#define PI 3.14159265

int main() {
	//modern C++ constant
	const float radius = 0.5;
	float area;
	
	area = PI * radius * radius;
	cout << "A circle with radius " << radius << " has area " << area << endl;
}
```

#### Output:
```
A circle with radius 0.5 has area 0.785398
```

# Operators
C++ uses the same operators as C.

| **Type**   | **Operators**                     | **Description**                                 |
| ---------- | --------------------------------- | ----------------------------------------------- |
| Arithmetic | `+`, `-`, `*`, `/`, `%`           | Add, subtract, multiply, divide, remainder      |
| Relational | `<`, `<=`, `>`, `>=`, `==`, `!=`  | Relational and equality checks                  |
| Logical    | `&&`                              |                                                 |
| Assignment | `=`, `+=`, `-=`, `*=`, `/=`, `%=` | Assignment and compound assignment              |
| Unary      | `++`, `++`                        | Increment, decrement (pre- and post-fix)        |
| Ternary    | `a ? b : c`                       | If `a` is true, evaluate `b`, else evaluate `c` |
