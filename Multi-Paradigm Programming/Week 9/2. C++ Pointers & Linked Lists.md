# Why pointers and linked lists?
- **Arrays vs. lists:**
	- **Arrays:** store data in contiguous memory. Fast lookup, but insertion/deletion is slow (requires shifting elements).
	- **Linked lists:** dynamic data structure. Memory expands/contracts as needed. Insertion/deletion is efficient (just changing pointers), but look-up is slower (must scan sequentially).
- **Pointers:** allow flexible data structures that change size/shape at runtime.

# 1. basic pointer concepts
- **Pointer:** a variable that stores a **memory address**.
- **Dereferencing (`*`):** accessing the object a pointer points to.
	- If `head` is a pointer, `*Head` is the actual object.
- **Assignment(`=`):** `P = Q` makes `P` point to the **same** object that `Q` points to.
- **Arrow operator (`->`):** shorthand for dereferencing and accessing a member.
	- `Head->Element` is equivalent to `(*Head).Element`.

# 2. dynamic memory allocation
In C++, you manually manage memory for dynamic structures.
- **`new` operator:**
	1. allocates memory for an object.
	2. calls the object's **constructor**.
	3. returns the **memory address** (pointer) to the object.
	- *Example:* `Node* Head = new Node;`
- **`delete` operator:**
	- Destroys the object pointed to and releases the memory.
	- *Example:* `delete Head;`.

# 3. linked list implementation
## The node class
A list consists of nodes containing data and a link to the next node.
```cpp
class Node {
	public:
		int Element; //data
		Node* Next; //pointer to the next node
}
```
- The end of a list is marked by `nullptr`.
- An empty list is when `Head == nullptr`.

## The list class structure
```cpp
class Intlist {
	private:
		Node* Head; //points to the start of the list.
	public:
		Intlist(); //constructor
		~Intlist(); //destructor
		//...operations like Insert, Delete, Print
};
```

# 4. key list operations
## Insertion (at the beginning)
To insert a new value:
1. create a new node: `new_node = new Node;`
2. set its data: `new_node->Element = value;`
3. point it to the current head: `new_node->Next = Head;`
4. update Head to point to the new node: `Head = new_node;`

## Printing/traversal
To process a list, use a temporary pointer. **Never** move `Head` directly or you lose the list.
```cpp
Node* temp = Head;
while (temp != nullptr) {
	//process temp->Element
	temp = temp->Next; //move to the next node
}
```

## Deletion
Deleting a specific value is more complex. You need to pointers: `temp` (current) and `previous` (one step behind).
1. **handle edge cases:** empty list, or deleting the very first node (head changes).
2. **traverse:** loop until `temp` finds the value or hits `nullptr`.
3. **re-link:** `previous->Next = temp->Next;` (skip over the node to be deleted).
4. **free memory:** `delete temp;`.

# 5. memory safety: the "big three"
When a class contains pointers (like `Intlist`), the default C++ copy behaviour is dangerous (Shallow Copy). You must implement specific functions to handle deep copying.

## 1. destructor (`~Intlist`)
Automatically called when the list object goes out of scope. It must iterate through the list and `delete` **every node** to prevent memory leaks.

## 2. copy constructor
Called when initialising a new object from an existing one (e.g., passing by value).
- **Default:** copies the pointer address only (both objects point to the *same* memory).
- **Required:** create a **Deep Copy**. You must iterate through the old list and `new` a separate node for every node in the original list.

## 3. assignment operator (`operator=`)
Called when assigning `List A = List B`.
- **Steps:**
	1. check for self-assignment (`if (this != &oldList)`).
	2. **clear** the existing list (delete all current nodes).
	3. **deep copy** the nodes from the source list.

# Summary of pointer operations
For dynamic structures, stick to these safe operations:
- Assignment (between pointers of same type).
- Comparison (`==`, `!=`).
- Passing/returning from functions.
- Dereferencing (`*`, `->`).
- `new` and `delete`.
