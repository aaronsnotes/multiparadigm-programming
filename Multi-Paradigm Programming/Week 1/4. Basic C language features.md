# Control structures and functions
- C has `if`, `while`, `for`, `do`, and `switch` statements, similar to Java.

---
# Void functions
These don't return anything, they just perform a task.
```c
void displayANumber(int number) {
	printf("Number: %d", num);
}
```
- Return in a void function terminates it early.

# One key difference in C: advance declaration of functions
- In C, functions need to be declared (and/or defined) in advance of using them.
	- Same as using variables.

---
## Option 1:
- Place the function definition above `main()`.
- **Pros:** `main()` now knows about the function in advance.
- **Cons:** pushes `main()` further down the file.

---
## Option 2:
- Two-stage declaration + definition (such as putting `void function();` at the beginning of the file, then function after `main()`).
- **Pros:**
	- `main()` knows about the function in advance but doesn't need full definition until later.
- **Cons:**
	- Duplication in code.

---
## Option 3:
- Header files.
- Put function declarations in separate file.
- `#include` them where required.
- Can share function definitions across many files.
- E.g:
```c
#include "functions.h"
```
**C is NOT object-oriented.**

# Arrays in C
- Declare an array of 10 numbers/integers.
```c
int numbers[10];
```
- Initialize numbers to -1:
```c
for (int i = 0; i < 10; i++) {
	numbers[i] = -1;
}
```
**NOTE:** in Java, arrays are declared like:
```java
int[] numbers = new int[10];
```
because Java is object-oriented.

In C, arrays are just consecutive memory locations.

*Initializing arrays is just like Python.*

- **In C:**
	- Arrays are just sequences of values stored in memory.
	- You **need** to be mindful of array size and bounds.
		- Although you can use `sizeup` function in *some* cases.
	- You **need** to manage the memory.
	- You **need** to do error checking and handling.

---
## Multi-dimensional arrays
```c
//Declare and initialise an array with two rows and three columns.
int numbers[2][3] = {
	{
		1, 2, 3
	},
	{
		4, 5, 6
	}
};

//iterate through rows and cols to display
for (int i = 0; i < 2; i++) {
	for (int j = 0; j < 3; j++) {
		printf("Next element: %d\n", numbers[i][j]);
	}
}
```

# Define a constant
- The `#define` statement.
- Typical usage: `#define CONSTANT value`
- E.g., `#define ARRAY_SIZE 20`
- Usually placed near top of C file.

*You can also use `#define` for error codes.*

---

#define COMMON_CODE for(int i = 0; i < 10; i++)
