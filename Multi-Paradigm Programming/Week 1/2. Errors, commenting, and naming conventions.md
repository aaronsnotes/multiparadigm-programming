# Errors
- **Compilation:** typos, syntax, missing semi-colons, etc.
- **Linking:** can't resolve variables or functions which are across several files, missing libraries, etc.
	- Clues will be errors such as 'undeclared' variables, 'undefined' functions, or 'redefined' variables.
- **Runtime:** logical errors in code, memory management issues, exceptions, file handling, etc.
	- **Common issue:** 'segmentation fault'. This is a memory fault, e.g., trying to access a 'null' pointer, failing to free memory that was allocated, program's 'stack' becoming full due to an infinite loop or similar.

# Naming conventions
- **C#, Java, C++ is commonly camel case:**
	- `myVariableName;`
	- `MyFunctionName()` or `myFunctionName();` e.g., `getPasswd();`
- **In C, you may often see underscores, referred to as Snake Case:**
	- `my_variable_name;`
	- `my_function_name();` e.g., `get_password();`
- In our C code, we will use camel case to have continuity with C++.
