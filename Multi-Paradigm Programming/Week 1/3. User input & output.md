# Data types in C

| **Type**         | **Size**                  | **Range**                                            | **Examples**          |
| ---------------- | ------------------------- | ---------------------------------------------------- | --------------------- |
| `char`           | 1 byte                    | -128 to 127, 0 to 255                                | 'c', '£', '3', ';'    |
| unsigned `char`  | 1 byte                    | 0 to 255                                             |                       |
| signed `char`    | 1 byte                    | -128 to 127                                          |                       |
| `int`            | 2/4 bytes                 | -32,768 to 32,767 or -2,147,483,648 to 2,147,483,647 | -203, 56, 78898, 12   |
| unsigned `int`   | 2/4 bytes                 | 0 to 65,535 ot 0 to 4,294,967,295                    |                       |
| `short`          | 2 bytes                   | -32,768 to 32,767                                    |                       |
| unsigned `short` | 2 bytes (4 for 32-bit OS) | 0 to 65,535                                          |                       |
| `long`           | 8 bytes                   | -9223372036854775808 to 9223372036854775807          | -203, 56, 78898, 12   |
| unsigned `long`  | 8 bytes                   | 0 to 18446744073709551615​                           |                       |
| `float`          | 4 bytes                   | 1.2E-38 to 3.4E+38 (6 decimals precision)            | 1.34, 6.7775, 564.002 |
| `double`         | 8 bytes                   | 2.3E-308 to 1.7E+308 (15 decimals precision)         |                       |
| `long double`    | 10 bytes                  | 3.4E-4932 to 1.1E+4932 (19 decimals precision)       |                       |
- *There's no string in C (but there is in C++) -- use char arrays instead.*

**Example:** display the value of an `int` variable `x` to the user.
```c
int x = 12;
printf("The value of 'x' is %d", x);
```
- `%d`: use format specifier to tell `printf` the datatype of the variable that is being displayed, AND where in output string the variable's value should be inserted.
- `, x`: also, give `printf` the name of the variable that holds the value you wish to display (almost like passing an arg through to `printf`).

**Output will be:** `The value of 'x' is 12.`

- `int` = `%d`
- `float` = `%f`
- `double` = `%lf` (long float)
- `char` = `%c`

scanf("%specifier", &storageVarName);

## Read in multiple values with `scanf`
### Read 2 numbers and char from user
```c
int num1;
double num2;
char ch;

printf("Enter int, double, and char.");
scanf("%d %lf %c", &num1, &num2, &ch);
```

## Strings in C
- There is no in-built string datatype in C.
	- Can't do `String myString;`.
- In C, strings are just (null-terminated) `char` arrays.
	- Need to do this: `char myString[30];`.

---
### Initialising strings in C
```c
char name[30] = "Craig";
char name[] = "Craig";
char name [] = {'C', 'r', 'a', 'i', 'g', '/0'};
```
- `/0`: a 'null' character -- needed to terminate the string.

See other methods later, e.g., string input, `<string.h>`, functions.

- *You cannot reassign strings using '=' -- use `strcpy()` or similar.*

---
### Why is a null terminator needed?
- Program won't know where the string ends.
```c
char name[30] = "Craig";
printf("My name is: %s", name);
```
- Would cause memory overflows or out-of-bounds errors.

---
## Reading strings with `scanf`
### String input/output
```c
//declare variable to hold string
char name[100];

//ask user for name
printf("Enter your name:");
scanf("%s", name);
//(neither safe nor robust)

//display name
printf("Your name is: %s\n", name);
```

---
### Issues with `scanf` and `char` arrays
- Clips/truncates input when white space entered.
```c
char name[100];
printf("Enter your name:");
scanf("%s", name); //John Smith

printf("Your name is: %s\n", name);
//-> Your name is: John
```
- *Can cause memory leaks if enter more than max amount of characters.*

---
### More workarounds
- Specify a limit on the number of chars for `scanf` to read.
```c
char name[100];
printf("Enter your name:");
scanf("%99s", name);
```
- Or use 'safer' input functions, such as `fgets();`.

---
### `scanf` may truncate or ignore inputs
- Truncating data and leaving data in the input buffer.
- You ask the user for an `int`, they enter this: `23.4`.
	- `scanf` reads `23`.
- You ask the user for an `int`, and they enter this: `t`.
	- `scanf` reads in nothing.
- How to check if `scanf` has read what's expected?
	- Check return value.

---
#### Checking `scanf` return value
- `scanf` returns a value, the number of items successfully read.
```c
if (scanf("%d", &num) != 1) {
	//didn't read in one int.
}

if (scanf("%d %c %lf", &num, &ch, &dbl) != 3) {
	//didn't read in expected 3 items.
}
```

---
## Other ways of reading inputs/strings
- `gets()`: read a string from the standard input.
	- Doesn't terminate at white space,
	- BUT unsafe! Can cause buffer to overflow. Removed from C11.
- `fgets()`: read a string of chars from a specified input stream (e.g., `stdin`).
	- Reads only up to a specified maximum - prevent overflow.
	- BUT: copies any `\n` characters into the string too -- may need to remove.
- See also:
	- `getline()`
	- Character reading functions: `getchar()`, `getc()`, `fgetc()`.

---
## String manipulation
- See `<string.h>`.
- **Examples:**
	- `strncpy`: copy up to `n` chars from one string to another.
	- `strncmp`: compare up to `n` chars between two strings.
	- `strlen`: get the length of a string.
	- `strdup`: duplicate a string by making another copy of it in memory.
- See also (in `<stdlib.h>):
	- `atoi`: convert a string to a int.
	- `atof`: convert a string to a float.

---
## String functions: `<string.h>`
```c
#include <string.h>

char name[30] = "Craig";
char name2[30] = "Jennifer";

int lengthOfString = strlen(name);

if strcmp((name, name2) == 0) {
	//name and name2 are the same.
}

strncpy(name, name2, 30);
```
